# Generic graphics implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Ship customizable, theme-aware inline graphics with responsive local interaction and an optional role resource pack.

**Architecture:** Rust core owns the bounded declarative protocol and pure validation/sampling; mdwasm exposes it to rendering workers. SolidJS renders validated typed blocks, preserving widget identity through streaming and virtual scroll. Existing assistant Markdown remains the persistence format.

**Tech Stack:** Rust/serde, existing wasm-bindgen/pulldown-cmark, SolidJS, native SVG, Web Workers, existing CSS theme variables.

**Spec:** `docs/superpowers/specs/2026-11-01-graphics-design.md` (binding interfaces and schema).

## Global Constraints

- No executable resource packs, eval, model scripts, external assets, DSH host, or React dependency.
- No production config/data/OAuth changes or production restarts. Work on main per Agent.md; user has approved implementation.
- Parent owns integration, version/changelog/docs, builds/tests and the final runtime smoke. Implementation agents skip builds/tests/lint/formatters and commits.
- Use exactly the core/WASM exports and JSON contracts in the spec. Original project licensing remains Apache-2.0 OR MIT.
- Complete widgets, theme adaptation, local interaction, historical replay, and cleanup; no placeholder renderers.

## Review Focus

- Invalid and oversized structured output must not crash messages or execute content: core validation tests plus a browser invalid-fence scenario.
- Slider results must not apply out of order or lose state on remount: actual interaction, rapid values, and virtual-scroll replay.
- Theme changes must recolor native and image SVG graphics: eight built-in themes and custom-token browser checks.
- Unfinished fences must keep stable widgets without error flicker: actual incremental source changes and DOM identity check.
- Logout/account switch must clear source/state/worker callbacks: existing account flow plus scoped cleanup smoke.
